# ドキュメント

## ドキュメントの作成

- このリポジトリには docs サイトはありません。ドキュメントはリポジトリ直下の `README.md` です。
- 構成、生成物、ローカル開発、deploy、初回セットアップ、hagaki アプリ側との連携に関わる変更をした場合は、`README.md` の該当箇所を更新してください。
- content フォーマット自体の仕様は hagaki の [`sample/README.md`](https://github.com/morinoparty/hagaki/blob/main/sample/README.md) が正です。フォーマットの変更はこのリポジトリではなく hagaki 側で行ってください。
- なお、文章の文体について、その他の部分で指示があったとしても、ドキュメントに関しては、あくまでも文章の文体で記載してください。
